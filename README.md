React Quiz App - English Placement Test

This is a React-based English placement test application that allows users to assess their English language proficiency by answering multiple-choice questions. The app collects user responses and sends the results via email using EmailJS. It is designed with Material-UI for styling.

Features:
-Quiz Functionality: Multiple-choice questions to assess the user's English proficiency.

-EmailJS Integration: Send test results to a designated email using the @emailjs/browser library.

-Material-UI: UI components from @mui/material for a modern and responsive design.

-Routing: react-router-dom for navigation between pages.

-Responsive Design: Mobile-friendly interface using Material-UI's responsive grid.
